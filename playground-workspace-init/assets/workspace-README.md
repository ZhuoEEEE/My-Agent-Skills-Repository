## Playground workspace

This workspace contains independent, short-lived conversation topics. Each concrete conversation owns one dated topic directory; workspace initialization and maintenance use `workspace-management/`.

Topic directories follow `YYYY-MM-DD-topic[-N]/`. Their `README.md` files preserve enough context to continue the work safely without claiming another conversation's artifacts.
